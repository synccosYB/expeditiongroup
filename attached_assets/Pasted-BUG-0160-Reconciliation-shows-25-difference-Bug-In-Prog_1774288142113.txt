Description

Reconciled and reviewed transactions four times, but the system still shows a $25 difference instead of clearing to $0.00. Appears to be a bug that needs to be fixed.

Resolution

Here's what I found and fixed:

Root cause: Task 164 on the "2 Summit Dr" project was deleted at some point, but its 32 linked notes stayed in the database still pointing to that deleted task. When the frontend tries to display notes under each task, those 32 notes don't match any existing task — so they become invisible.

Two fixes applied:

Immediate data recovery — When the app starts up, it automatically detects any notes pointing to deleted tasks and converts them to project-level notes so they become visible again. For the "2 Summit Dr" project, all 32 notes will reappear under the "Project-Level Notes" section at the top of the Tasks tab.

Future prevention — When a task is deleted going forward, its notes are automatically unlinked (set to project-level) instead of being left pointing to a non-existent task. This ensures notes are never lost again.

Once you publish, the fix will run automatically on startup. You'll see those 32 notes appear in the "2 Summit Dr" project — from there you can re-link them to the correct tasks using the link dropdown if needed.
