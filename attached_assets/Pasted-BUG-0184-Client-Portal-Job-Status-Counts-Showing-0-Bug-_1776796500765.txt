Description

In the client portal, all job status categories (Open, On Hold, Completed) are displaying as 0, even though jobs exist in the system.

Resolution

The fix that shipped:

Flipped the default for new projects to visible to client (admins can still turn it off per project if they want to hide one).
Backfilled every existing project in the database to visible, so ExpeditionGroup (and any other affected client) immediately see correct counts in Intake, In Progress, Waiting on Client, With DOB, On Hold, Completed, and Cancelled.
Confirmed the admin project edit screen still lets you hide an individual project from a client when needed.
You should now be able to log in as the ExpeditionGroup client and see real numbers in the Job Pipeline instead of zeros.
