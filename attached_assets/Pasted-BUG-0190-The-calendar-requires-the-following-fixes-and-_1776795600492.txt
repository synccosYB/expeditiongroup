Resolution

Here's a summary of all the fixes made for BUG-0190:

Fixes implemented:

Fixed broken time entries display — Both the calendar task dialog and the tasks page had a critical bug where the time entries query used queryKey: ["/api/time-entries", { taskId: task?.id }]. The { taskId } object was being stringified to [object Object] in the URL, causing the fetch to hit a non-existent endpoint. Time entries were silently failing to load. Fixed to use the correct endpoint: queryKey: ["/api/tasks", task?.id, "time-entries"]. This means time log entries from the calendar now properly sync and display under project time logs.

"Today" button now opens a dedicated day view — Clicking "Today" now switches to a new Day view mode (like Google Calendar) showing only that day's tasks and reminders in a clean, focused list format with sections for Tasks and Reminders, rather than just navigating within the month grid.

Added Day view tab — A new "Day" tab alongside Month and Week lets users switch to a single-day focused view. Navigation arrows step one day at a time in this mode.

Smoother drag-and-drop — Reduced pointer activation distance (8→5px) and touch delay (200→150ms) for more responsive dragging. Added visual improvements: better grip handle hover states, enhanced drop zone highlighting with subtle scale effect, and improved drag overlay card with stronger shadow and border.

Notes and notes history already work — The Notes tab in the calendar task dialog already saves internal notes and shows change history, synced with the main task data.
