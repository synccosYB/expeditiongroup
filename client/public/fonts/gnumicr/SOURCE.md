# GnuMICR font source

Original author: Eric Sandeen, copyright 2000–2003.

Source: https://github.com/alerque/gnumicr (GnuMICR version 000.300).

The files GnuMICR.raw, README and COPYING are unchanged upstream files downloaded on 2026-10-15. GnuMICR.raw is the font's preferred editable source, licensed under GPL version 2 or later; see COPYING and the original author's distribution notes in README. Keep all these files together when distributing the font.

The application's renderer loads this separate source at runtime and interprets the outline operators to produce print-sized PDF vector paths. No converted TTF or font glyph data is built into the application bundle.
